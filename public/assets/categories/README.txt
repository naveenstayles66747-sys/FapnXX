# 🏷️ CATEGORY HERO IMAGES FOLDER

Yahan har Category ki Hero Cover Image daali ja sakti hai.
Image file ka naam Category ke Slug / ID ke hisab se rakho:

- `trending.jpg` (ya `.webp` / `.png`) -> Trending Category
- `desi.jpg` (ya `.webp` / `.png`) -> Desi Category
- `amateur.jpg` (ya `.webp` / `.png`) -> Amateur Category
- `milf.jpg` (ya `.webp` / `.png`) -> MILF Category
- `teen.jpg` (ya `.webp` / `.png`) -> Teen Category
- `anal.jpg` (ya `.webp` / `.png`) -> Anal Category
- `lesbian.jpg` (ya `.webp` / `.png`) -> Lesbian Category
- `asian.jpg` (ya `.webp` / `.png`) -> Asian Category
- `pov.jpg` (ya `.webp` / `.png`) -> POV Category
- `hentai.jpg` (ya `.webp` / `.png`) -> Hentai Category
- `vr.jpg` (ya `.webp` / `.png`) -> VR Category
- `default.jpg` -> Kisi nayi ya unmapped category ke liye fallback image

### 📐 Recommended Dimensions:
- Ratio: 16:9 (e.g. 1280x720 ya 800x450 px)
- Format: JPG, WEBP, ya PNG

💡 **Note**: Jaise hi aap `desi.jpg` ya koi bhi image yahan rakhoge, website par Categories page aur Category Detail page pe wo image live ho jayegi!
